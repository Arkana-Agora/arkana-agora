# Glossario -- Arkana Agora

Este glossario define os termos tecnicos e de dominio utilizados em toda a documentacao do projeto `arkana-agora`.

---

## Tarot

| Termo | Definicao |
|-------|----------|
| **Arcano Maior** | Conjunto de 22 cartas (0 a 21) que representam arquétipos universais e forcas cosmicas. Inclui O Louco, O Mago, A Sacerdotisa, A Imperatriz, O Imperador, O Hierofante, Os Amantes, O Carro, A Forca, O Eremita, A Roda da Fortuna, A Justica, O Enforcado, A Morte, A Temperanca, O Diabo, A Torre, A Estrela, A Lua, O Sol, O Julgamento e O Mundo. |
| **Arcano Menor** | Conjunto de 56 cartas divididas em 4 naipes (Copas, Paus, Espadas, Ouros), cada um com 14 cartas (As a 10 + 4 figuras: Valete, Cavaleiro, Rainha, Rei). |
| **Tiragem** | Ato de selecionar e dispostas cartas para uma leitura. Tambem chamada de "jogada" ou "consulta". |
| **Espalhamento (Spread)** | Padrão de disposição das cartas na mesa, definindo posicoes e significados contextuais. |
| **Posicao** | Cada slot dentro de um espalhamento, com significado proprio (ex.: passado, presente, futuro). |
| **Carta Revelada** | Carta cuja face ficou visivel apos a tiragem, gerando a interpretacao. |
| **Carta Invertida** | Carta que aparece de cabeca para baixo na tiragem, alterando ou intensificando seu significado. |
| **Baralho Rider-Waite-Smith (RWS)** | Baralho padrao da plataforma Arkana Agora, criado por Arthur Edward Waite e ilustrado por Pamela Colman Smith em 1909. |
| **Pergunta do Consulente** | Questao ou tema que o usuario traz para a tiragem, que contextualiza a interpretacao. |
| **Consulta** | Sinonimo de tiragem; sessao completa de leitura de cartas. |
| **Significador** | Carta escolhida para representar o consulente dentro da tiragem (opcional na plataforma). |

## Baralho Cigano (Lenormand)

| Termo | Definicao |
|-------|----------|
| **Lenormand** | Sistema oracular com 36 cartas, atribuido a Marie Anne Lenormand (1772-1843), popularizado no Brasil como "Baralho Cigano". |
| **36 Cartas** | Conjunto completo do baralho Lenormand, com imagens simbolicas simples (Cavaleiro, Ancora, Navio, Casa, Arvore, etc.). |
| **Grande Tableau** | Espalhamento que utiliza todas as 36 cartas, oferecendo uma visao abrangente da vida do consulente. |
| **Tiragem Linear** | Leitura de 3 a 5 cartas em linha, interpretadas pela relacao de proximidade e combinacao. |
| **Combinacao de Cartas** | Tecnica de interpretacao onde cartas adjacentes ou proximas modificam mutuamente seus significados. |
| **Casa Lenormand** | Posicao fixa no Grande Tableau, cada uma com tema proprio (coracao, anel, caixa, etc.). |
| **Ponte** | Carta colocada entre duas outras para entender a conexao ou transicao entre elas. |

## Numerologia

| Termo | Definicao |
|-------|----------|
| **Numerologia Pitagorica** | Sistema numerologico baseado nos ensinamentos de Pitagoras, que associa numeros a letras do alfabeto. |
| **Numero de Expressao** | Calculado a partir da soma dos valores numerologicos de todas as letras do nome completo. Revela talentos e habilidades naturais. |
| **Numero de Motivacao (Alma)** | Calculado a partir das vogais do nome. Revela desejos profundos e motivacoes interiores. |
| **Numero de Impressao (Personalidade)** | Calculado a partir das consoantes do nome. Revela como o individuo e percebido pelos outros. |
| **Numero de Destino** | Calculado pela reducao da data de nascimento completa. Revela o proposito de vida. |
| **Reducao Pitagorica** | Tecnica de soma dos digitos de um numero ate obter um digito unico (1-9), com excecao dos numeros mestres (11, 22, 33). |
| **Numero Mestre** | Numeros 11, 22 e 33 que nao sao reduzidos, pois possuem significado amplificado. |
| **Tabela Pitagorica** | Tabela de correspondencia entre letras e numeros (A=1, B=2, C=3, ..., I=9, J=1, K=2, etc.). |
| **Arcano Pessoal** | Corresponde ao Numero de Destino reduzido ao intervalo 0-21, mapeando para um Arcano Maior do Tarot. |

## Calendario Maia (Tzolkin)

| Termo | Definicao |
|-------|----------|
| **Tzolkin** | Calendario sagrado maia de 260 dias, combinacao de 20 Selos Solares com 13 Tons Galacticos. |
| **Kin** | Numero de ordem de um dia no ciclo Tzolkin (1 a 260). Cada Kin combina um Selo Solar com um Tom Galactico. |
| **Selo Solar** | Um dos 20 simbolos do Tzolkin (Dragao, Vento, Noite, Semente, Serpente, etc.), representando energia arquetipica. |
| **Tom Galactico** | Um dos 13 numeros (1 a 13) que qualifica a expressao do Selo Solar. |
| **Onda Encantada** | Ciclo de 13 dias no Tzolkin, iniciado por um mesmo Selo Solar nos 13 Tons. |
| **Castelo** | Periodo de 52 dias no Tzolkin, agrupando 4 Ondas Encantadas. |
| **Data de Referencia** | 26/07/1954, utilizada como Kin 1 (Dragao 1) para o calculo de qualquer Kin a partir de uma data gregoriana. |
| **Calendario Haab** | Calendario solar maia de 365 dias, usado em conjunto com o Tzolkin para formar o Calendario Conta Longa. |
| **Poder de Escolha** | Direcao cosmica associada ao Kin do dia, sugerindo postura ou acao reflexiva. |

## Horoscopo Chines

| Termo | Definicao |
|-------|----------|
| **Zodiaco Chines** | Ciclo de 12 animais: Rato, Boi, Tigre, Coelho, Dragao, Serpente, Cavalo, Cabra, Macaco, Galo, Cao, Porco. |
| **Ciclo Sexagenario** | Ciclo de 60 anos formado pela combinacao dos 12 animais com os 5 elementos (Madeira, Fogo, Terra, Metal, Agua). |
| **Ano Lunar** | Ano do calendario chines, iniciando entre 21 de janeiro e 20 de fevereiro, que determina o signo e elemento do ano. |
| **Elemento Chines** | Cinco fases ou elementos: Madeira, Fogo, Terra, Metal, Agua. Cada animal pode manifestar-se em um destes elementos. |
| **Trine (Afiliacao)** | Agrupamento de 4 signos compativeis: Rato-Macaco-Dragao (1a trine), Boi-Serpente-Galo (2a trine), Tigre-Cavalo-Cao (3a trine), Coelho-Cabra-Porco (4a trine). |
| **Yin/Yang** | Polaridade associada a cada signo: alternadamente yin (passivo/receptivo) e yang (ativo/criativo). |

## Horoscopo Ocidental

| Termo | Definicao |
|-------|----------|
| **Signo Zodiacal** | Uma das 12 divisoes da ecliptica (Aries, Touros, Gemeos, Cancer, Leao, Virgem, Libra, Escorpiao, Sagitario, Capricornio, Aquario, Peixes). |
| **Ascendente** | Signo que estava no horizonte leste no momento exato do nascimento. Requer hora de nascimento para calculo. |
| **Mapa Astral (Natal)** | Diagrama completo das posicoes planetarias no momento do nascimento. |
| **Casa Astrológica** | Cada uma das 12 divisoes do mapa astral, representando areas da vida. |
| **Regressao** | Movimento aparente retrógrado de um planeta, que na astrologia tradicional indica revisao ou atraso. |

## Tecnologia

| Termo | Definicao |
|-------|----------|
| **SSE (Server-Sent Events)** | Protocolo de comunicacao unidirecional servidor->cliente usado para streaming de interpretacoes IA em tempo real. |
| **RBAC (Role-Based Access Control)** | Modelo de controle de acesso baseado em papeis (roles) que define permissoes por grupo de usuarios. |
| **PWA (Progressive Web App)** | Aplicacao web que funciona como app nativo, com suporte a instalacao, cache offline e notificacoes push. |
| **LGPD** | Lei Geral de Protecao de Dados (Lei 13.709/2018), legislacao brasileira que regula o tratamento de dados pessoais. |
| **Next.js** | Framework React para producao, com suporte a SSR, SSG, API routes e otimizacao automatica. |
| **Prisma** | ORM (Object-Relational Mapper) TypeScript para banco de dados, com migrations declarativas e type safety. |
| **Zustand** | Biblioteca de gerenciamento de estado leve para React, usada para estado global do cliente. |
| **TanStack Query** | Biblioteca para gerenciamento de estado de servidor (cache, sincronizacao, revalidacao) em aplicacoes React. |
| **shadcn/ui** | Biblioteca de componentes UI reutilizaveis baseados em Radix UI e Tailwind CSS. |
| **Framer Motion** | Biblioteca de animacao para React, usada nas transicoes de revelacao de cartas. |
| **z-ai-web-dev-sdk** | SDK para integracao com modelos de linguagem (GPT-4o), utilizado para geracao de interpretacoes. |
| **GPT-4o** | Modelo de linguagem da OpenAI utilizado para gerar interpretacoes de cartas com contexto e fluencia em portugues. |
| **Docker** | Plataforma de conteinerizacao usada para empacotar e distribuir a aplicacao de forma consistente. |
| **CI/CD** | Pipeline de Integracao Continua e Entrega Continua, automatizando testes e deploy. |
| **Mercado Pago** | Gateway de pagamento brasileiro, utilizado para processar assinaturas e transacoes do marketplace. |
| **Monorepo** | Repositorio unico contendo multiplos pacotes/aplicacoes, gerenciado com ferramentas como Turborepo. |
| **SQLite** | Banco de dados relacional embarcado, utilizado em desenvolvimento. Em producao, migra para PostgreSQL. |
| **PostgreSQL** | Banco de dados relacional robusto, utilizado em ambiente de producao do arkana-agora. |
| **NextAuth.js v4** | Biblioteca de autenticacao para Next.js, com suporte a OAuth, credenciais e JWT. |
| **Tailwind CSS 4** | Framework CSS utility-first, utilizado para estilizacao da interface. |

## Social e Plataforma

| Termo | Definicao |
|-------|----------|
| **Verso** | Unidade de conteudo compartilhavel na plataforma (tiragem, calculo, texto reflexivo). |
| **Feed** | Linha do tempo com versos de usuarios seguidos e conteudo sugerido. |
| **Marketplace** | Espaco para profissionais oferecerem servicos de leitura, consultoria e produtos esotericos. |
| **Gift (Presente)** | Item virtual que usuarios podem enviar uns aos outros como forma de apreciacao. |
| **Arkana Plus** | Plano de assinatura premium da plataforma, com beneficios como 10 tiragens por dia e acessos exclusivos. |
| **Freemium** | Modelo de negocio onde funcionalidades basicas sao gratuitas e avancadas requerem assinatura. |
| **Tarot do Dia** | Tiragem diaria automatica com uma unica carta, disponivel gratuitamente para todos os usuarios. |
| **Historico** | Registro de todas as tiragens e leituras realizadas pelo usuario na plataforma. |
| **Perfil** | Pagina pessoal do usuario com dados de identificacao, arcano pessoal, kin maya e estatisticas. |
| **Follow (Seguir)** | Acao de acompanhar um usuario para ver seus versos no feed. |
| **Profissional** | Usuario verificado que oferece servicos no marketplace. |
| **Moderacao** | Processo de revisao e filtro de conteudo gerado pelos usuarios, garantindo conformidade com Termos de Uso. |
| **DM (Direct Message)** | Mensagem direta entre usuarios (planejada para fases futuras). |
