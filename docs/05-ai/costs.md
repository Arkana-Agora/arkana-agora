## Estratégias de Redução de Custo

### 1. Caching (maior impacto)

| Métrica | Sem cache | Com cache (40% hit) | Economia |
|---------|-----------|---------------------|----------|
| Leituras/mês (10K users) | 180.000 | 108.000 chamadas | **40%** |
| Custo/mês | $2.600 | $1.560 | **$1.040** |

> **Implementação**: Redis com TTL 24h, chave = hash(cartas + data + user).

### 2. Modelo Otimizado por Tarefa

| Tarefa | Antes (GPT-4o) | Depois (GPT-4o-mini) | Economia/req |
|--------|---------------|---------------------|-------------|
| Horóscopo | $0,0003 | $0,0003 | já otimizado |
| Sim/Não | $0,0070 | $0,0011 | 84% |
| Chat simples | $0,0035 | $0,0007 | 80% |

> **Cuidado**: Qualidade deve ser avaliada antes de migrar features para mini.

### 3. Otimização de Prompts

| Estratégia | Economia estimada | Risco de qualidade |
|-----------|-------------------|-------------------|
| Reduzir system prompt (800 → 500 tokens) | ~15% | Baixo |
| Remover exemplos do prompt | ~10% | Médio |
| Comprimir descrição das cartas | ~20% | Médio |
| Prompt em inglês com instrução de resposta pt-BR | ~30% | Alto (qualidade pt-BR) |

### 4. Prompt Caching (OpenAI)

OpenAI oferece desconto de 50% para prompts em cache (prefixos estáticos).

| Componente | Tokens | Com cache | Economia |
|-----------|--------|-----------|----------|
| System prompt base | 800 | 50% off | $0,004/req |
| Cartas (mesmo deck) | 500 | 50% off | $0,0025/req |
| **Total economizado/leitura** | | | **$0,0065** |

> Com 180K leituras/mês = **$1.170/mês economizados**.

### 5. Batch Processing

Para horóscopos diários (não interativos), processar em lote:

- Horóscopos são gerados às 03:00 (UTC-3)
- Batch de todos os usuários com horóscopo pendente
- Preço batch: 50% mais barato

### Resumo de Economia

| Estratégia | Economia/mês (10K users) | Esforço |
|-----------|-------------------------|---------|
| Caching (Redis) | $1.040 | Médio |
| Model Router (mini para simple) | $520 | Baixo |
| Prompt Caching (OpenAI) | $1.170 | Baixo |
| Otimização de prompts | $390 | Médio |
| Batch horóscopos | $30 | Baixo |
| **Total** | **$3.150** | |

> Com todas as estratégias: custo cai de $2.600 para **~$1.300/mês** (50% de redução).
